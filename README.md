# gd2nds-docs

Documentation site for [gd2nds](https://github.com/Kliiyu/gd2nds), a compiler that turns Godot 4.7 2D projects into Nintendo DS `.nds` ROMs.

Live site: https://kliiyu.github.io/gd2nds-docs/

## Local preview

```sh
pip install -r requirements.txt
mkdocs serve
```

Pushes to `main` are built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.
